# BlackAccWorld — Verified Reviews, Bank Accounts & Aged PVA Marketplace

Live Marketplace for high-retention 5-star reviews, US business bank accounts (Mercury, Chase, Relay), and aged PVA digital profiles.

## Features
- **53+ Curated Services**: Google Reviews, Trustpilot Verified Reviews, Yelp, Business Bank Accounts, Aged Gmail/Telegram/GitHub.
- **Client-Side Crypto Checkout**: Multi-chain cryptocurrency payment calculation & receipt generator (USDT, BTC, ETH, SOL, LTC, etc.).
- **1-Time Free Replacement Warranty**: Automated warranty request flow & real-time order tracker.
- **Deep SEO Architecture**: Semantic keywords, FAQ rich schemas, dynamic title/meta tag manipulation.

## GitHub Pages Deployment
This repository is configured with GitHub Actions (`.github/workflows/deploy.yml`) to automatically build and publish to GitHub Pages upon pushing to `main`.

### To enable GitHub Pages in your repository:
1. Go to your repository **Settings** on GitHub.
2. Click **Pages** (in the left sidebar under Code and automation).
3. Under **Build and deployment > Source**, select **GitHub Actions**.
4. The site will deploy to `https://affisaas.github.io/blackaccworld/`.
